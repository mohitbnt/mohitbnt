## 🚀 Featured Cloud & DevOps Projects

### 🧱 AWS Infrastructure with Terraform

Designed and deployed production-oriented AWS infrastructure using Terraform with a focus on **security, high availability, modularity, and automation**.

**Key implementations:**

* Built reusable Terraform configurations using variables, locals, data sources, and `templatefile()`.
* Designed VPC networking with **public and private subnets across multiple Availability Zones**.
* Deployed an **Application Load Balancer and Auto Scaling Group** for highly available workloads.
* Configured EC2 Launch Templates with **IMDSv2, GP3 volumes, IAM roles, and CloudWatch monitoring**.
* Implemented **VPC Interface Endpoints** for AWS Systems Manager (`ssm`, `ssmmessages`, `ec2messages`) to manage private EC2 instances without exposing SSH to the internet.
* Configured **S3 Gateway Endpoints** for private S3 connectivity.
* Implemented remote Terraform state using **Amazon S3 with versioning and state locking**.
* Applied security group rules following least-privilege principles.
